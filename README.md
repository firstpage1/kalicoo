# Kalicoo website

GitHub Pages preview package prepared for `firstpage1/kalicoo`.

Upload the **contents of this folder** to the root of the `main` branch, then enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / (root)**.

Do not add a `CNAME` file until the preview has been approved, so the existing Wix-hosted `kalicoo.com` remains untouched.
